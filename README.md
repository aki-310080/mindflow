# MindFlow - MindMeister Style Web App

Chrome拡張機能不要・ブラウザ単体で動作する、MindMeister（マインドマイスター）同等の操作感を備えたWebマインドマップアプリです。

## 特徴

1. **MindMeisterライクな直感的キーボード操作**
   * `Tab`: 選択ノードに子ノードを追加（即時入力モード）
   * `Enter`: 兄弟ノードを追加
   * `Delete`: ノード削除
   * `Space + ドラッグ`: 広大なキャンバスを自由にパン（画面移動）
2. **サイドバー＋大画面の統合1画面UI**
   * 左サイドバーで複数マップの作成・切り替え・削除を管理。
   * サイドバーは `☰` ボタンでワンクリック折りたたみ可能（集中時はフル画面キャンバス）。
3. **画像・リンクのペースト / 添付対応**
   * ノードを選択して `Ctrl + V` を押すだけで、スクリーンショットや画像を即時埋め込み。
   * デスクトップからの画像ドラッグ＆ドロップに対応。
   * URLを貼り付けるとクリック可能なリンクバッジが自動付与。
4. **ブラウザ内大容量データベース（IndexedDB）＆ ファイル保存**
   * 画像を含む大容量マップもブラウザ内の `IndexedDB` に高速・自動保存（オフライン対応）。
   * マップを `.json` ファイルとしてPCにバックアップ保存／再読み込みが可能。
5. **エクスポート機能**
   * Markdown（`.md`）および PNG画像への書き出しに対応。

## 起動方法（今すぐ使う手順）

### 方法1: ダブルクリックで簡単起動（Windows）
フォルダ内にある [**start-mindflow.bat**](start-mindflow.bat) をダブルクリックしてください。
自動的にローカルサーバーが起動し、既定のブラウザでMindFlowが開きます。

### 方法2: コマンドで起動
```bash
cd C:\Users\am080\My_Github\MY_PC3\scripts\mindmap-extension
npm run dev
```

### 静的ビルド（Vercel / GitHub Pages 等へのデプロイ用）
```bash
npm run build
```
`dist/` フォルダ内に完全な静的Webサイトとして出力されます。
