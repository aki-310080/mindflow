# 05. MindMeister操作感・インタラクション完全再現仕様書 (MindMeister UX Specification)

## 1. 目的と基本方針

本拡張機能における最優先事項は、単にマインドマップの機能を持つことではなく、**「MindMeister（マインドマイスター）特有の、吸い付くような気持ち良い手触り・操作感（UX）」を徹底的に再現すること**です。

思考のスピードを1ミリ秒も落とさない流れるようなキーボード操作と、物理的な心地よさを感じる滑らかなアニメーション・ドラッグ挙動を定義します。

---

## 2. 操作感の核心：7つのインタラクション原則

```
+--------------------------------------------------------------------------+
|                 MindMeister 操作感（UX）の 7大コア要素                   |
|                                                                          |
|  1. ゼロ遅延・即時インライン編集 (Tab / Enter 連打で思考を止めない)     |
|  2. スムーズな物理補間アニメーション (ノードの展開・折りたたみ・再配置)  |
|  3. ドロッププレビュー付きドラッグ＆ドロップ (挿入位置の視覚ガイド)      |
|  4. ノード追従型フローティングメニュー (マウス近接時・選択時の素早い装飾)|
|  5. 直感的なパン＆ズーム (慣性スクロール, トラックパッド対応, センタリング)  |
|  6. 矢印キーによる空間的フォーカス移動 (見た目どおりにノードを移動)     |
|  7. ベジェ曲線のテンションとブランチのカラーグラデーション             |
+--------------------------------------------------------------------------+
```

---

## 3. 詳細インタラクション仕様

### 3.1 キーボード主体の超高速ノード生成（思考のフロー維持）
MindMeister最大の美点は、**「キーを叩いた瞬間にノードが生まれ、即座に文字入力ができること」**です。

| 操作 | 挙動の詳細仕様 |
| :--- | :--- |
| **`Tab` (子ノード作成)** | 1. 選択ノードの右側（または下位）に滑らかなトランジションで新しい子ノードが出現。<br>2. **即座にテキスト入力カーソルが点滅（インライン編集モード）**。<br>3. ユーザーはマウスに触れることなく、そのまま文字をタイプできる。 |
| **`Enter` (兄弟ノード作成)** | 1. 選択ノードと同じ階層の「すぐ下」に兄弟ノードが挿入される。<br>2. 自動的に全体のレイアウトが押し広げられ（アニメーション）、重なりを回避。<br>3. 即座にインライン編集モードへ移行。 |
| **`Shift + Enter` (上側に兄弟ノード作成)** | 選択ノードの「すぐ上」に兄弟ノードを挿入。 |
| **`Enter` 確定後の連続操作** | 文字入力中に `Enter` を1回押すと確定（非編集モード）。<br>続けてもう一度 `Enter` を押すと、即座に次の兄弟ノードが作られて編集モードになる。 |
| **`Esc` (キャンセル / 確定)** | 編集を終了し、現在のノードを選択状態のまま維持。 |
| **`Delete` / `Backspace`** | 選択ノードを削除。フォーカスは自動的に親ノードへ自然に移動する。 |

---

### 3.2 矢印キー（↑ ↓ ← →）による空間移動
マウスを使わずに、画面に見えている幾何学的な位置関係に基づいて選択ノードを切り替えます。
* `→`（右矢印）：子ノードの先頭にフォーカス移動。
* `←`（左矢印）：親ノードにフォーカス移動。
* `↑` / `↓`（上下矢印）：同階層の兄弟ノード間を行き来。
* **心地よさのポイント**: 移動した際、選択枠（フォーカスリング）が「ポンッ」と小さく弾むようなスケーリングアニメーション（Scale 1.05 → 1.0）を付与。

---

### 3.3 ドラッグ＆ドロップ（DnD）の吸着挙動
MindMeisterのノード組み換えは、ドロップ先が直感的にわかるガイド表示が特徴です。

```
[ドロップ挙動のプレビュー表示]

(A) 子ノードにする場合:
    [移動中ノード] ────>  ┌──────────────┐
                          │ 既存のノード │ <── ノード全体が青くハイライト
                          └──────────────┘

(B) 兄弟として間に挿入する場合:
    ┌──────────────┐
    │ ノード A     │
    └──────────────┘
    ━━━━━━━━━━━━━━━━  <── 青い挿入インジケーター線（水平バー）が表示
    ┌──────────────┐
    │ ノード B     │
    └──────────────┘
```

* **ホバー判定（吸着）**:
  * 対象ノードの**中央エリア**に重ねた場合：そのノードの「子」にするハイライト。
  * 対象ノードの**上下境界付近**に重ねた場合：「兄弟ノードとして割り込み挿入」するガイドライン表示。
* **ドロップ時アニメーション**:
  * 指を離した瞬間、ノードが新しい位置へと滑らかにスライド移動して定着する（Snap & Slide）。

---

### 3.4 ブランチの展開・折りたたみアニメーション
* **トグル操作**:
  * ノードの端にある丸い「丸数字バッジ（子ノードの件数）」または `+` / `-` をクリック。
* **アニメーション**:
  * 折りたたむ際、下位のサブツリー全体が親ノードの背後へ**スッと吸い込まれるようにフェードアウト（Collapse）**。
  * 展開する際、扇状に広がりながらノードがスライドして現れる（Expand）。
  * 展開・折りたたみに伴い、周囲の他のブランチも重ならないよう滑らかに位置を譲り合う。

---

### 3.5 キャンバスのナビゲーション（パン＆ズーム）
MindMeisterのキャンバス移動は、Googleマップのような非常に滑らかなパン・ズームを提供しています。

* **スペースキー + ドラッグ**:
  * マウスカーソルが「手のひら（Grab）」になり、キャンバス全体を自由自在にスクロール。
* **マウスホイール**:
  * 上下スクロール：縦移動。
  * `Ctrl` + ホイール（またはトラックパッドのピンチ操作）：マウスカーソルの位置を中心として滑らかにズームイン・ズームアウト。
* **ダブルクリックで新規浮動ノード (Floating Node)**:
  * キャンバスの何もない空白エリアをダブルクリックすると、どのツリーにも属さない独立したアイデアルートノードを作成可能。
* **センタリングボタン**:
  * 迷子になった際、画面右下の「中央に戻る」アイコンを押すと、アニメーションしながら全体が見渡せる位置へ戻る（Fit to Screen）。

---

### 3.6 ノードデザインとベジェ曲線の質感
* **ブランチ（接続線）のカーブ**:
  * 直線やカクカクした折れ線ではなく、**三次ベジェ曲線（Cubic Bezier Curve）**を用いた美しいしなりを持つ曲線。
  * 親ノードに近いほど太く、末端にいくほど自然に細くなる線の強弱。
* **カラーリング**:
  * ルートから枝分かれするメインブランチごとに固有のアクセントカラー（青、緑、オレンジ、紫など）を割り振り、その子孫ノードは同系色の淡いカラーを引き継ぐ「自動カラーテーマ」。
* **ノードのタイポグラフィ & 余白**:
  * 窮屈感のない適度なパディング（上下6px, 左右12px）、角丸（Border-radius: 8px〜12px）。
  * 文字数に応じてノード幅がリアルタイムに自然伸縮するリキッドデザイン。

---

### 3.7 クイックスタイリング・ツールバー（コンテキストメニュー）
* ノードを選択した際、またはノード上で右クリックした際、ノードのすぐ上に**フローティング・ミニツールバー**が小さくポップアップ。
  * 背景色の変更パレット
  * 文字の太字（Bold）/ イタリック
  * アイコン（チェックマーク、星、警告など）の1クリック挿入
  * リンク・画像追加ボタン

---

### 3.8 画像の貼り付け・ドラッグ＆ドロップ（Image Attachment）
MindMeister同様、視覚的なインスピレーションを保つためのシームレスな画像添付仕様：

* **クリップボードからの直接ペースト (`Ctrl + V` / `Cmd + V`)**:
  * ノードを選択した状態でスクリーンショットやコピーした画像を `Ctrl + V` すると、即座にそのノード内（テキストの上部）にサムネイル画像として埋め込まれる。
* **デスクトップからのドラッグ＆ドロップ**:
  * 画像ファイル（PNG, JPG, WebP, GIF）をPCからドラッグしてノードの上に落とすと自動添付。
* **表示と挙動**:
  * ノードの横幅に合わせて画像がアスペクト比を維持したまま美しくリサイズ（角丸クリッピング）。
  * 画像をクリックすると、拡大モーダル（ライトボックス表示）で原寸大プレビュー。
  * 画像右上にある「×」アイコンでワンクリック削除。

---

### 3.9 リンク（URL）の貼り付けとスマートプレビュー（Hyperlink Integration）
* **URLの自動認識 & ペースト**:
  * ノード選択中にURL（`https://...`）をペーストすると、自動的にリンク属性が付与される。
* **ビジュアル表示**:
  * ノードのテキスト末尾に小さな「外部リンクアイコン（↗）」または対象サイトの「ファビコン（16x16px）」が表示される。
* **クリック時の挙動**:
  * アイコンをクリックすると、新しいタブでスムーズに対象Webページを開く。
  * マインドマップ側の編集画面を邪魔しないバックグラウンドタブオープンにも対応。

---

## 4. 実装における技術的アプローチ

この「MindMeisterの操作感」をChrome拡張機能で100%実現するための実装方針：

1. **`mind-elixir` のイベントフックとCSSカスタマイズ**:
   * `mind-elixir` はコアエンジンとして非常に優秀ですが、デフォルトのCSSはやや角張っており、アニメーションが控えめです。
   * これに対し、専用のCSSトランジション（`transition: transform 0.2s cubic-bezier(0.25, 1, 0.5, 1);`）を当て込み、MindMeister特有の「バネのような心地よい弾力」を再現します。
2. **キーボードイベントの完全捕捉**:
   * IME（日本語入力）確定の `Enter` と、ノード生成の `Enter` が競合しないよう、`isComposing`（変換中判定）を厳密に制御。
   * 「日本語入力確定ではノードを作らず、確定後の `Enter` で次のノードが生まれる」という、日本のユーザーにとって自然な操作感を保証します。
