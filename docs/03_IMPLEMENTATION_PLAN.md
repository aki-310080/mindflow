# 03. 詳細実装計画書 (Implementation Plan & WBS)

## 1. 開発進行アプローチ

本プロジェクトは、**「段階的プロトタイピング（Iterative Prototyping）」**により進行します。
初期段階で複雑な機能をすべて実装しようとせず、まずは最小構成（サイドパネルでマインドマップが表示され、キーボード操作できる状態）を最短で作り、実機（Chrome）で動作検証を行いながら機能を追加・拡張していきます。

---

## 2. フェーズ別 WBS (Work Breakdown Structure)

```
[Phase 1] MVP基盤構築 (Core Mindmap in Sidepanel)
   ├── 1.1 プロジェクト初期化 (Vite + TypeScript)
   ├── 1.2 manifest.json 設定 & Sidepanel 画面の作成
   ├── 1.3 mind-elixir の組み込み & キャンバス初期化
   └── 1.4 Chromeへのテスト読み込み & キーボード操作検証

[Phase 2] データ永続化 & マップ管理 (Storage & Management)
   ├── 2.1 chrome.storage.local ラッパー層の実装
   ├── 2.2 オートセーブ（Debounce保存）機能
   ├── 2.3 複数マップ切り替え UI (ドロップダウン / 一覧)
   └── 2.4 新規マップ作成 & マップ削除ロジック

[Phase 3] ブラウザ連携機能 (Chrome Context Menu & Extraction)
   ├── 3.1 background service worker の実装
   ├── 3.2 右クリックメニュー (chrome.contextMenus) 登録
   ├── 3.3 バックグラウンド ⇄ サイドパネル間のメッセージング
   └── 3.4 閲覧中ページのURL・タイトル取得 & ノード追加ボタン

[Phase 4] 全画面ビュー & エクスポート (Fulltab & Export)
   ├── 4.1 fulltab.html (全画面用ビュー) の実装
   ├── 4.2 サイドパネル ⇄ フルタブのリアルタイムデータ同期
   ├── 4.3 Markdown / JSON エクスポート処理の実装
   └── 4.4 PNG / SVG 画像ダウンロード機能

[Phase 5] UI最適化 & パッケージング (Refinement & Build)
   ├── 5.1 MindMeisterライクなカラーパレット & CSSチューニング
   ├── 5.2 サイドパネル幅に最適化したズーム・レイアウト調整
   └── 5.3 Chrome Web Store 向け ZIP パッケージング検証
```

## 3. 各フェーズの詳細作業手順

### Phase 1: MVP基盤構築
* **所要目安**: 1〜2日
* **作業内容**:
  1. `npm create vite@latest . -- --template vanilla-ts` 等でプロジェクトを初期化。
  2. `mind-elixir` パッケージをインストール。
  3. `manifest.json` に `side_panel`, `storage` 権限を記述。
  4. `sidepanel.html` で `div#map` を用意し、TSスクリプトから初期マインドマップを描画。
* **完了条件**:
  * Chromeの「拡張機能の管理」から「パッケージ化されていない拡張機能を読み込む」で導入できる。
  * ブラウザのサイドパネルにマインドマップが表示され、`Tab` で子ノード、`Enter` で兄弟ノードが追加できる。

### Phase 2: データ永続化 & マップ管理
* **所要目安**: 2〜3日
* **作業内容**:
  1. `mind.getData()` で取得できるツリーJSONを `chrome.storage.local` に保存する関数を作成。
  2. ノード変更イベント（`operation`）を検知し、500msのデバウンスで自動保存。
  3. 次回サイドパネル起動時に、前回のマップデータを自動復元。
  4. 画面上部にマップ名表示と、新規作成（クリア）ボタンを設置。
* **完了条件**:
  * Chromeを再起動したりサイドパネルを閉じたりしても、入力したマインドマップの内容が完全に保持されていること。

### Phase 3: ブラウザ連携機能
* **所要目安**: 2〜3日
* **作業内容**:
  1. `background.ts` で `chrome.contextMenus.onClicked` をリッスン。
  2. ユーザーがWebページ上のテキストを選択して右クリックした際、テキストを抽出して `chrome.runtime.sendMessage` でサイドパネルへ送信。
  3. サイドパネル側でメッセージを受信し、現在フォーカスされているノード（なければルートノード）の子ノードとしてテキストを自動挿入。
* **完了条件**:
  * 任意のWebページでテキストを選択して右クリックすると、サイドパネルのマインドマップに即座にノードとして追加されること。

### Phase 4: 全画面ビュー & エクスポート
* **所要目安**: 2日
* **作業内容**:
  1. `fulltab.html` を作成し、別タブで同じマップを画面いっぱいに描画できるようにする。
  2. サイドパネル右上またはツールバーに「全画面で開く（新しいタブ）」アイコンを配置。
  3. `chrome.storage.onChanged` を実装し、タブ側で編集した内容がサイドパネル側にも自動反映される（逆も同様）。
  4. `mind.exportPng()` や自前のMarkdownシリアライザでエクスポートボタンを実装。
* **完了条件**:
  * 大画面でマインドマップの編集ができ、MarkdownファイルとしてPCに保存できること。

### Phase 5: UI最適化 & パッケージング
* **所要目安**: 1〜2日
* **作業内容**:
  1. ノードの角丸、接続線のベジェ曲線、フォントサイズなどをMindMeister風にスタイリング。
  2. サイドパネル幅（約350px）でも操作しやすいよう、初期表示時のズーム倍率を自動調整。
  3. `npm run build` を実行し、生成された `dist/` ディレクトリで正常に動作することを確認。
* **完了条件**:
  * 本番ビルド成果物が警告・エラーなしで動作し、拡張機能として完成していること。

## 4. 開発環境・前提条件

* **Node.js**: v18.0.0 以上
* **パッケージマネージャー**: npm または pnpm
* **動作対象ブラウザ**: Google Chrome 116以上（Side Panel API が安定動作するバージョン）
