# 01. プロジェクト概要書 (Project Overview)

## 1. プロジェクトの背景と目的

### 1.1 背景
現代のナレッジワーカーや学習者は、Webブラウザ上で大量の情報を収集・調査（リサーチ）しています。しかし、一般的なマインドマップツール（MindMeister、XMindなど）を使用する場合、以下のような分断が発生します：
* Webブラウザとデスクトップアプリ（または別タブ）を頻繁に往復する必要がある。
* 閲覧中のWeb記事からテキストやリンクをコピー＆ペーストする作業が思考のフローを中断させる。
* 「今考えていること」を一時的にメモ・整理するだけの用途に対して、重厚なクラウドツールを立ち上げるのが億劫になる。

### 1.2 目的
本プロジェクトは、世界的なマインドマップ作成ツール**「MindMeister（マインドマイスター）」の持つ高速な思考整理体験（思考を止めないキーボード操作）**を、**Google Chrome拡張機能**としてブラウザのすぐ横（サイドパネル）に再現・常駐させることを目的とします。

---

## 2. コア・コンセプトと提供価値

### 2.1 3大コンセプト
1. **Full-Canvas Thought Space（広大なフル画面キャンバスを主軸に）**
   * MindMeisterの醍醐味である広大なキャンバスを犠牲にしないため、マインドマップ本体の編集は**「フルスクリーン（専用タブ）」**で大画面で行う。
   * 画像のドラッグ＆ドロップ貼り付けや、外部リンクの埋め込みも大画面で快適に操作。
2. **Side Panel as Command Center（サイドパネルはマップ管理＆司令塔）**
   * サイドパネルは「マインドマップを描く場所」ではなく、**「マップの一覧・作成・整理、Webページをストックする管理センター」**として機能。
   * Web記事を読みながら、ワンクリックでリンクやメモを目的のマップへ送り、見たいマップをワンクリックで大画面で呼び出す。
3. **Rich Content Integration（画像・Webリンクの直感的ペースト）**
   * クリップボードからの画像貼り付け（`Ctrl + V`）や画像ファイルのドラッグ＆ドロップでノードに画像を配置。
   * WebサイトのURLを貼り付けると、クリック可能な外部リンク（ファビコン付き）としてノードに統合。

## 3. ターゲットユーザー & ユースケース

### 3.1 ターゲットユーザー
* **Webリサーチャー・調査担当者**: 複数サイトを行き来しながら論点をマインドマップにまとめたい人。
* **エンジニア・開発者**: 技術ドキュメントやAPI仕様を読みながら、設計・アイデアを構造化したい人。
* **学習者・学生**: オンライン教材や論文を読みながら要約マップを作りたい人。
* **企画・ライター**: ブログや記事構成、プレゼン構成案をWeb情報を元に練りたい人。

### 3.2 代表的ユースケース
* **ケース1: Web記事の論点整理**
  1. 記事を読みながらサイドパネルを開く。
  2. 重要なキーワードを選択して右クリック「ノードに追加」。
  3. `Tab` キーで自分の考えや考察を子ノードとして追記。
* **ケース2: プレゼン・企画の構成案出し**
  1. フルタブで広大なキャンバスを開く。
  2. MindMeister同様にキーボードだけでブレインストーミングを行いツリーを広げる。
  3. Markdown形式でエクスポートし、そのままドキュメント作成へ引き継ぐ。

## 4. プロジェクトスコープ

### 4.1 In Scope（初期〜中期で開発・提供するもの）
* Chrome Manifest V3 準拠の拡張機能
* サイドパネル（Side Panel）表示およびフルタブ表示
* キーボードショートカットを中心とするマインドマップ編集（追加・削除・編集・移動）
* ノードの自動レイアウトと折りたたみ・展開機能
* `chrome.storage.local` による完全ローカル・オフラインでのデータ永続化
* 複数マップ（ドキュメント）の切り替え・新規作成・削除
* Webページからのテキスト引用（コンテキストメニュー連携）
* エクスポート機能（JSON、Markdown、PNG画像）

### 4.2 Out of Scope（初期段階では対象外とするもの）
* リアルタイム複数人同時編集（クラウドバックエンドやWebSocketが必要となるため、フェーズ1〜2では見送り）
* 独自認証アカウント管理（Chromeローカル完結を最優先とする）
* モバイルブラウザ対応（デスクトップ版Chromeを対象とする）
